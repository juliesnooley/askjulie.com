Who's collecting these

Julie Handel

I trained in accounting and I've homeschooled four children in San Jose for the last decade. I started keeping these prompts because I kept re-typing the same instructions and kept getting the same failure — plausible, confident output that fell apart the moment a real seven-year-old sat down in front of it.

So the ones here are the ones that held up. Most of them are long because the constraints are doing the work. The instruction telling the model not to recommend books it isn't sure exist is not decoration; it is the difference between a usable list and an afternoon at the library looking for something that was never written.

Nothing here is a course, and I'm not selling anything. If a prompt fails for you, say so on it — that's more useful to the next parent than another success story.
